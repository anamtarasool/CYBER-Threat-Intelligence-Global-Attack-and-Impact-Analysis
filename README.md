# CYBER-Threat-Intelligence-Global-Attack-and-Impact-Analysis
Cyber Threat Intelligence analyzes global cyberattacks, identifies attack patterns, tracks financial losses, and highlights trends through interactive dashboards to support better cybersecurity decisions.
Cyber Threat Intelligence: Global Attacks & Impact Analytics
Project Overview
This project presents an interactive Cyber Threat Intelligence Dashboard developed using Microsoft Power BI. It explores global cybersecurity incidents, attack patterns, financial losses, affected users, and targeted industries to support data-driven understanding of cyber threats.
The dashboard provides an overview of cybersecurity risks through interactive charts, KPI cards, and filters.
Project Objectives
- Analyze cyberattack patterns across countries and years.
- Examine financial losses associated with different attack types.
- Identify targeted industries and common security vulnerabilities.
- Compare attack sources and their impact on affected users.
- Present complex cybersecurity data in an accessible, interactive format.
Tools and Technologies
- Microsoft Power BI: Dashboard development and visualization
- Power Query: Data preparation and transformation
- DAX: Measures and KPI calculations
- Microsoft Excel: Dataset storage and initial review
Dashboard Overview

The dashboard includes interactive slicers for Country, Year, Target Industry, Attack Type, and Attack Source.

Dashboard Visualizations
1. Financial Loss by Country: Compares reported financial losses across countries, including the UK, Germany, Brazil, Australia, and others.
2. Financial Loss by Attack Type: Donut chart showing the distribution across DDoS, phishing, SQL injection, ransomware, malware, and man-in-the-middle attacks.
3. Security Vulnerability Types: Treemap comparing zero-day vulnerabilities, unpatched software, social engineering, and weak passwords.
4. Attack Distribution by User Impact: Pie chart showing high, medium, and low user-impact categories.
5. Industry and Year Analysis: Matrix displaying financial-loss figures across target industries and years.
6. Affected Users by Attack Source: Column chart comparing nation-state, unknown, insider, and hacker-group sources.
7. Financial Loss and Percentage by Industry: Combination chart comparing industry-level financial losses and percentages.
8. Financial Loss and Affected Users by Year: Trend visualization comparing the two measures over time.
Key Insights
- DDoS attacks account for the largest share of financial loss among the attack types shown in the donut chart, at approximately 18.24%.
- Phishing accounts for approximately 17.62%, followed by SQL injection at approximately 16.61%.
- The security-vulnerability treemap shows zero-day as the largest category by attack count (785), followed by social engineering (747), unpatched software (738), and weak passwords (730).
- The attack-source chart shows approximately 0.39 billion affected users for both nation-state and unknown sources, followed by insiders (0.38 billion) and hacker groups (0.35 billion).
- The dashboard supports comparisons across countries, industries, attack categories, and time periods using interactive filters.
Business Value
This analysis can help stakeholders:
- Recognize prominent cyberattack types and vulnerabilities.
- Understand the relative financial impact of different threats.
- Prioritize cybersecurity awareness and risk-management efforts.
- Explore which industries and countries experience greater reported impact.
- Communicate cybersecurity trends using clear visual summaries.
Limitations
- Findings depend on the completeness, accuracy, and coverage of the underlying dataset.
- Dashboard values represent the dataset and should not be treated as verified global cybersecurity totals.
- Correlation and visual trends do not establish the causes of cyber incidents.
- Financial units and the definition of the HR metric should be checked against the original dataset before external reporting.
Future Scope
- Integrate regularly updated cybersecurity incident data.
- Add threat severity and risk-scoring measures.
- Include predictive analysis to explore possible future trends.
- Develop drill-through pages for country- and industry-specific analysis.
Conclusion
The Cyber Threat Intelligence Dashboard transforms cybersecurity incident data into interactive visual insights. By examining attack types, vulnerabilities, financial losses, affected users, and targeted industries, the project demonstrates how business intelligence can support cybersecurity monitoring and informed decision-making.
